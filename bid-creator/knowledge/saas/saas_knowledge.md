# SaaS 云平台知识库

## SaaS 模式特点

### 1. 服务模式

| 模式 | 说明 | 优势 |
|------|------|------|
| 标准 SaaS | 多租户共享资源 | 成本低 |
| 私有化 SaaS | 独立资源隔离 | 安全性高 |
| 混合模式 | 标准+私有化结合 | 灵活 |

### 2. 计费模式

| 模式 | 说明 |
|------|------|
| 订阅制 | 按月/年订阅 |
| 用量制 | 按实际使用量计费 |
| 订阅+用量 | 基础订阅 + 超额用量 |

## 功能模块（SaaS 版）

### 1. 应用性能监控

提供完整的应用性能监控能力，开箱即用。

主要功能包括：应用接入（Agent 接入/SDK 接入）、实时监控（QPS/RT/错误率）、事务追踪（完整调用链）、告警配置（阈值告警/趋势告警）、数据可视化（Dashboard/报表）。

### 2. 前端监控

无需部署，前端 JS 接入即可使用。

主要功能包括：JS 接入（CDN/npm）、性能监控（页面性能/加载时间）、错误监控（JS 错误/资源错误）、用户行为（访问路径/停留时间）、AJAX 监控（请求成功率/响应时间）。

### 3. 基础设施监控

云原生监控能力，集成主流云平台。

主要功能包括：云主机监控（CPU/内存/磁盘/网络）、容器监控（K8S/Docker）、数据库监控（MySQL/Redis/MongoDB）、自定义监控（指标接入/告警）。

### 4. 告警中心

多通道告警，分钟级响应。

主要功能包括：告警规则（阈值/趋势/同环比）、通知渠道（邮件/短信/钉钉/企微/飞书）、告警升级（未响应自动升级）、告警抑制（重复告警合并）、告警管理（认领/处理/关闭）。

### 5. 团队协作

多人协作，权限管理。

主要功能包括：团队管理（添加成员/角色权限）、应用管理（创建/删除/转让）、成员管理（邀请/移除/角色）、操作日志（审计追踪）、API Token（开放 API）。

## SaaS vs 私有化对比

| 对比项 | SaaS | 私有化 |
|--------|-----|--------|
| 部署方式 | 云服务 | 本地部署 |
| 实施周期 | 1-3 天 | 1-4 周 |
| 运维成本 | 无需运维 | 需要运维 |
| 数据安全 | 云端安全 | 数据本地化 |
| 定制能力 | 标准功能 | 可定制 |
| 扩展性 | 自动扩容 | 需手动扩容 |
| 成本 | 订阅制 | 一次性 |

## SaaS 常见问题 FAQ

### Q1: 数据安全性如何保障？
**A**: 数据传输加密（HTTPS）、存储加密、访问控制、操作审计、多地域容灾。

### Q2: 如何接入系统？
**A**: 注册账号 → 创建应用 → 接入 Agent/SDK → 开始监控。

### Q3: 支持哪些语言/框架？
**A**: Java/Python/Go/Node.js/PHP/.NET 等主流语言，Spring/Django/Flask/Express 等主流框架。

### Q4: 数据保留多长时间？
**A**: 标准版 7 天，专业版 30 天，企业版定制。

### Q5: 可以导出数据吗？
**A**: 支持 API 导出和报表导出。
