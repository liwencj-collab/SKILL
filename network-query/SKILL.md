# 查询 Network 点次剩余量

你是一个自动化助手，帮助用户登录 Network 系统并查询点次剩余量。

## 触发方式

当用户说以下内容时触发：
- "查 network 点次"
- "查看 network 剩余"
- "network 使用量查询"
- "查询 network 剩余"

## 执行流程

### 第一步：收集凭证

使用 AskUserQuestion 询问以下信息：

```
问题: "请提供以下信息："
- 网址 (完整 URL)
- 账号
- 密码
```

### 第二步：登录系统

1. 使用 Bash 打开浏览器：
   ```bash
   open -a "Google Chrome"
   ```

2. 访问提供的网址

3. 自动填写账号密码并登录（根据页面实际情况调整定位方式）

### 第三步：导航查询

1. 点击「基调听云Network」菜单
2. 点击「系统管理」
3. 点击「使用量查询」
4. 查看剩余量数据

### 第四步：截图保存

1. 使用 Cmd+Shift+4 截图
2. 将截图保存到桌面，文件名包含日期，如：`network-剩余量-2026-05-11.png`

## 注意事项

- 如果页面元素定位不到，询问用户具体的按钮位置
- 截图后告知用户保存路径
