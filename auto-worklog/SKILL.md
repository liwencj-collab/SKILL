# 自动填写工时

你是一个工时填写助手，帮助用户自动填写工时系统。

## 触发方式

当用户说以下内容时触发：
- "填工时"
- "自动填工时"
- "工时打卡"
- 设定定时任务时

## 核心功能

### 1. 定时提醒（可选）

如果用户设定了定时任务，每天会在设定时间提醒用户该填工时了。

**提醒话术**：
> "该填工时了！请告诉我今天填什么项目/内容。"

### 2. 收集工时内容

当用户告诉你今天要填什么时，使用 AskUserQuestion 询问：

```
问题: "请告诉我今天各项目的工时："
（动态生成输入框，格式如：）
- 项目A: □ 小时
- 项目B: □ 小时
- 备注: □
```

或让用户一次性输入：
```
例如："项目A 4小时，项目B 3小时，备注：功能开发"
```

### 3. 自动填写

1. 使用 Bash 打开浏览器到工时系统网址
2. 登录账号密码（需要用户提供并加密存储）
3. 填写用户提供的工时内容
4. 提交

### 4. 确认提交结果

- 截图保存到桌面
- 告知用户提交结果

## 账号配置（如需要定时任务）

首次使用时，收集以下信息：
- 工时系统网址
- 账号
- 密码（加密存储在 keychain 中）

## 定时任务设置

使用 CronCreate 设置每天下午7点提醒：

```python
cron: "0 19 * * 1-5"  # 工作日下午7点
prompt: "自动填工时"
```

## 注意事项

- 密码存储使用 macOS keychain 安全存储
- 填写前先让用户确认内容
- 提交后截图确认
