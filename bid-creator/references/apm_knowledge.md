### 3. 基础设施监控
- 服务器监控
- 数据库监控
- 容器监控
- 云平台监控

### 4. 前端监控 (RUM)
- 页面加载时间
- AJAX 请求监控
- 错误追踪
- 用户行为分析

### 5. 私有化平台能力（如涉及）
- 部署架构设计

- 扩容方案

## 常见专业术语

| 术语 | 说明 |
|------|------|
| APM | Application Performance Management，应用性能管理 |
| RUM | Real User Monitoring，真实用户监控 |
| SLA | Service Level Agreement，服务等级协议 |
| RT | Response Time，响应时间 |
| TPS | Transactions Per Second，每秒事务数 |
| ApDex | Application Performance Index，应用性能指数 |
| KPI | Key Performance Indicator，关键绩效指标 |
| SLA | Service Level Agreement，服务等级协议 |

---

## 响应时间标准

| 响应级别 | 响应时间 | 用户感知 |
|----------|----------|----------|
| 优秀 | < 1秒 | 流畅 |
| 良好 | 1-3秒 | 可接受 |
| 较差 | 3-5秒 | 明显延迟 |
| 极差 | > 5秒 | 难以接受 |

---

## 监控指标体系

### 1. 响应时间指标
- 平均响应时间
- 百分位响应时间 (P50/P90/P99)
- 最大响应时间

### 2. 吞吐量指标
- QPS (每秒请求数)
- TPS (每秒事务数)
- 并发用户数

### 3. 错误率指标
- 错误率
- HTTP 错误分布
- 异常类型分布

### 4. 可用性指标
- 系统可用率
- 成功率
- SLA 达标率
